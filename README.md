# voltran-openenv

Gerçek bir dil modelini (Qwen2.5-0.5B-Instruct) [OpenEnv](https://github.com/huggingface/OpenEnv) ortamlarında RL ile eğitip RL optimizasyon yöntemlerini aynı koşullarda karşılaştırma deneyi.

Algoritmalar [post_train_Detailed/voltran](https://github.com/AltanReisoglu/post_train_Detailed/tree/main/voltran) öğrenme kitinden geliyor. Bu repo onları oyuncak modelden gerçek bir LLM'e ve gerçek bir ortam arayüzüne taşıyor.

Hedef donanım: tek bir RTX 4060 Laptop (8 GB).
